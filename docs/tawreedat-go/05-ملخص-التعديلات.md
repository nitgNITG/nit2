## أولاً: التعديلات الحرجة (كانت مفقودة تماماً)

| # | التعديل | الملف المُعدَّل |
|---|---|---|
| ١ | إضافة متطلبات KYC إلزامية: رقم قومي + سجل تجاري + بطاقة ضريبية + حساب بنكي | العقد + دليل الانضمام |
| ٢ | تحديد الأرقام الفعلية كشرط لإبرام العقد — لا خانات فارغة | ملحق ٢ |
| ٣ | آلية التحقق من طلبات القنوات الخارجية (موافقة موثَّقة من العميل قبل الإنشاء) | الملحق المالي + الدليل |
| ٤ | ضوابط الطلبات الحرة: التسعير داخل التطبيق فقط، حدود للسعر | الملحق المالي + الدليل |
| ٥ | الاحتياطي المتدحرج ٥٪ لمدة ١٤ يوماً لحماية من الاسترداد بعد التسوية | الملحق المالي |
| ٦ | تجميد نصيب المتجر حتى تأكيد التسليم (لا توزيع فوري) | الملحق المالي |
| ٧ | حدود صريحة للرصيد النقدي للمندوب + إيقاف تلقائي | الملحق المالي |
| ٨ | آلية ضمان المندوب: وديعة تأمينية أو ضامن شخصي | الملحق المالي |
| ٩ | إضافة مادة حدود المسؤولية (Liability Cap) في العقد | العقد |
| ١٠ | إضافة مادة حماية البيانات وفق قانون ١٥١ لسنة ٢٠٢٠ | العقد + الدليل |
| ١١ | إضافة نظام تحذير تدريجي (أصفر / برتقالي / أحمر) بدلاً من الإيقاف المفاجئ | الدليل |
| ١٢ | إضافة مؤشرات أداء ملزِمة مع أرقام | ملحق ٢ + الدليل |
| ١٣ | إضافة مادة القوة القاهرة | العقد |
| ١٤ | إضافة إجراء الطعن والتظلم في قرارات المنصة | العقد + الدليل |
| ١٥ | تحديد مدة الرد على الشكاوى (٢٤ ساعة أولي / ٧٢ ساعة حسم) | الدليل |

## ثانياً: تعديلات الملحق المالي (١)

|---|---|

| ٨ | منظومة مكافحة الاحتيال المالي |
