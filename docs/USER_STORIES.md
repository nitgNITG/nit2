## Epic 1: Authentication

| ID | Story | Priority | Points |
|----|-------|----------|--------|
| US-001 | كمستخدم جديد، أريد التسجيل بالبريد الإلكتروني وكلمة مرور، لكي أتمكن من استخدام التطبيق | P0 | 3 |
| US-002 | كمستخدم مسجل، أريد تسجيل الدخول بسرعة، لكي أصل لختماتي | P0 | 2 |
| US-003 | كمستخدم نسيت كلمة مروري، أريد إعادة تعيينها برمز OTP، لكي لا أفقد حسابي | P0 | 3 |
| US-004 | كمستخدم، أريد الخروج من جميع الأجهزة، لكي أحمي حسابي | P1 | 2 |
| US-005 | كمستخدم، أريد التسجيل برقم الهاتف فقط (بدون إيميل)، لسهولة الاستخدام | P1 | 3 |

**Acceptance Criteria for US-001:**
```
GIVEN مستخدم جديد
WHEN يملأ نموذج التسجيل بإيميل وكلمة مرور صحيحة واسم
THEN يتم إنشاء الحساب
AND يُعاد توجيهه للوحة التحكم
AND يتلقى JWT في cookie

WHEN يستخدم إيميلاً موجوداً
THEN يرى رسالة "البريد الإلكتروني مستخدم"
AND لا يُنشأ حساب مكرر
```

## Epic 3: Part Reservation

| ID | Story | Priority | Points |
|----|-------|----------|--------|
| US-020 | كمشارك في ختمة، أريد رؤية الأجزاء المتاحة والمحجوزة، لكي أختار جزءاً | P0 | 3 |
| US-021 | كمشارك، أريد حجز جزء بنقرة واحدة، لكي يكون سريعاً | P0 | 3 |
| US-022 | كمشارك، أريد رؤية تغيير الحالة فوراً بدون تحديث الصفحة، لتجربة سلسة | P0 | 5 |
| US-023 | كمشارك أتممت الجزء، أريد تسجيل الإتمام، لكي يعرف الجميع | P0 | 3 |
| US-024 | كمشارك، أريد رؤية من حجز كل جزء، لمتابعة تقدم الجميع | P1 | 2 |
| US-025 | كمشارك، لا أريد أن أحجز جزءاً إذا كان لدي جزء آخر محجوز، لتوزيع عادل | P0 | 3 |

**Acceptance Criteria for US-021:**
```
GIVEN مشارك نشط في ختمة
AND الجزء 5 متاح

WHEN ينقر على "حجز الجزء الخامس"
THEN يتم الحجز خلال < 300ms
AND يتغير لون الجزء للمحجوز
AND يظهر اسمه على الجزء
AND يتلقى تأكيداً

GIVEN شخصان يحاولان حجز نفس الجزء في نفس الوقت
WHEN يُرسل الطلبان
THEN يحجز الأول
AND يتلقى الثاني "الجزء محجوز بالفعل"
AND بيانات DB سليمة (لا تعارض)
```
