## BR-001: Part Reservation Rules

| Rule ID | Rule | Enforcement Layer |
|---------|------|------------------|
| BR-001-1 | كل جزء يمكن حجزه من شخص واحد فقط في نفس الوقت | DB Unique Constraint + Redis Lock |
| BR-001-2 | الجزء المحجوز لا يمكن حجزه من شخص آخر حتى يُحرَّر | Service Layer |
| BR-001-3 | المستخدم لا يحجز أكثر من جزء في نفس الختمة (إلا إذا `allowRepeat = true`) | Service Layer |
| BR-001-4 | إذا كان `allowRepeat = true`، يمكن حجز أجزاء متعددة | Service Layer |
| BR-001-5 | الجزء المكتمل لا يمكن إلغاؤه أو حجزه مجدداً | Service Layer |
| BR-001-6 | إذا انتهى الـdeadline بدون إتمام، يُحرَّر الجزء تلقائياً | Cron Job |

## BR-002: Khatma Membership Rules

| Rule ID | Rule |
|---------|------|
| BR-002-1 | المستخدم لا يمكنه الانضمام لنفس الختمة مرتين |
| BR-002-2 | إذا كانت الختمة تتطلب موافقة، يبقى المستخدم في حالة PENDING حتى الموافقة |
| BR-002-3 | إذا امتلأت الختمة (maxMembers)، لا يُقبل أي عضو جديد |
| BR-002-4 | مغادرة الختمة تحرر الجزء المحجوز (إن وجد) |
| BR-002-5 | لا يمكن الانضمام لختمة مكتملة أو مغلقة |
| BR-002-6 | صاحب الختمة لا يمكنه مغادرتها، فقط حذفها |

## BR-003: Khatma Completion Rules

| Rule ID | Rule |
|---------|------|
| BR-003-1 | الختمة تكتمل تلقائياً عند إتمام الجزء الثلاثين |
| BR-003-2 | عند الاكتمال، تُرسَل إشعارات لجميع المشاركين |
| BR-003-3 | إذا كانت `isContinuous = true`، تُعاد الختمة تلقائياً |
| BR-003-4 | في الختمة المستمرة، يُحتفظ بسجل كل دورة (iteration) |
| BR-003-5 | إذا كان `autoRedistribute = true`، تُعاد توزيع الأجزاء المتأخرة على المتاحين |

## BR-004: Group Rules

| Rule ID | Rule |
|---------|------|
| BR-004-1 | فقط أعضاء المجموعة يمكنهم رؤية الختمات الحصرية للمجموعة (GROUP_ONLY) |
| BR-004-2 | المجموعة المغلقة تتطلب دعوة للانضمام |
| BR-004-3 | يمكن لمالك المجموعة فقط حذفها |
| BR-004-4 | المشرف يمكنه إدارة الأعضاء لكن لا يمكنه تغيير صلاحيات المالك |

## BR-005: Invitation Rules

| Rule ID | Rule |
|---------|------|
| BR-005-1 | رابط الدعوة ينتهي بعد 48 ساعة (قابل للضبط) |
| BR-005-2 | رابط الدعوة يمكن استخدامه مرة واحدة فقط إذا كان للمستخدم بعينه |
| BR-005-3 | رابط الدعوة العام يمكن استخدامه من أي شخص حتى الانتهاء أو الإلغاء |
| BR-005-4 | المستخدم المعلَّق لا يمكنه قبول الدعوات |

## BR-006: Privacy & Visibility Rules

| Visibility | سلوك |
|-----------|------|
| PUBLIC | يظهر في القائمة العامة، يمكن الانضمام بدون دعوة |
| PRIVATE | لا يظهر في القائمة العامة، يتطلب رابط دعوة |
| GROUP_ONLY | يظهر فقط لأعضاء المجموعة |

## BR-007: Individual vs Collective Khatma

| القاعدة | INDIVIDUAL | COLLECTIVE |
|--------|-----------|-----------|
| المشاركون | المنشئ فقط | متعددون |
| maxMembers | 1 (مقفل) | قابل للضبط |
| allowRepeat | اختياري | اختياري |
| يُعرض للعموم | لا | نعم (إذا PUBLIC) |

## BR-009: Auto Redistribution Logic

```
TRIGGER: كل 6 ساعات (Cron Job)

IF autoRedistribute = true AND endDate IS SET:
  1. احسب الوقت المتبقي
  2. اعثر على الأجزاء المحجوزة منذ أكثر من (remainingTime / remainingParts × threshold)
  3. إرسال تذكير للمستخدمين المتأخرين
  4. إذا تجاوز الحد: حرر الجزء وأرسل إشعاراً
```

## BR-010: Quran Parts Numbering

- الأجزاء: 1 → 30 (ثابتة)
- كل ختمة تُنشئ 30 سجل `QuranPart` عند إنشائها
- الأرقام لا تتغير ولا تُعاد ترقيمها
- الترتيب في الواجهة: 1 → 30 دائماً
