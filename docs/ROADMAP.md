## Phase 2 — Growth (Weeks 9–20)

**Theme:** "تجربة أفضل، نمو أسرع"

| Feature | Description |
|---------|-------------|
| Individual Khatma | ختمة شخصية بدون مشاركين |
| Continuous Khatma | تُعاد تلقائياً عند الاكتمال |
| Auto Redistribution | إعادة توزيع الأجزاء المتأخرة |
| Start/End dates + reminders | تحديد مواعيد + تذكيرات تلقائية |
| Google OAuth | تسجيل دخول بـGoogle |
| Email notifications | إشعارات بريدية |
| Admin Dashboard | إحصائيات + إدارة المستخدمين |
| SEO — Explore page | صفحة استعراض الختمات العامة |
| Advanced user statistics | إحصائيات الأجزاء المكتملة تاريخياً |
| PWA Support | تثبيت كتطبيق على الهاتف |
| WhatsApp share | مشاركة مباشرة عبر WhatsApp |

## Phase 3 — Scale & Intelligence (Month 6+)

**Theme:** "ختمة ذكية"

| Feature | Description |
|---------|-------------|

| Voice Tracking | تتبع التلاوة بالصوت |

| School Khatmas | للمدارس والجامعات |

## Long-term Vision (Year 2+)

- منصة اجتماعية قرآنية شاملة
- تكامل مع تطبيقات القرآن الكريم الكبرى
- برامج حفظ القرآن المدعومة بـAI
- شبكة من الشيوخ والمقرئين
- مبادرات الختم الخيرية العالمية
