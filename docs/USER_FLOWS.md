# User Flows
# ختمة — Khatma Platform

---

## Flow 1: إنشاء ختمة جديدة

```
مستخدم مسجل
    │
    ├── يضغط "إنشاء ختمة جديدة"
    │
    ├── [Wizard Step 1] اسم + وصف + نوع (فردية/جماعية)
    │       ↓ التالي
    ├── [Wizard Step 2] خصوصية + موافقة + تكرار + تواريخ
    │       ↓ التالي
    ├── [Wizard Step 3] مراجعة + إنشاء
    │       ↓ إنشاء
    ├── [API] POST /khatmas → يُنشئ 30 جزء
    │       ↓
    ├── [شاشة النجاح] "تم إنشاء الختمة"
    │       ↓
    └── [Share Screen] رابط + زر نسخ + مشاركة
```

---

## Flow 2: الانضمام بالرابط

```
شخص يتلقى رابط ختمة
    │
    ├── يفتح: https://khatma.app/join/ABC123
    │
    ├── [غير مسجل] → صفحة تسجيل سريع → تسجيل → انضمام تلقائي
    │
    ├── [مسجل، لم يدخل] → تسجيل دخول → انضمام تلقائي
    │
    ├── [مسجل، دخل] → انضمام تلقائي
    │
    ├── [Public، بدون موافقة] → ACTIVE مباشرة → صفحة الختمة
    │
    └── [مع موافقة] → PENDING → "طلبك قيد المراجعة"
```

---

## Flow 3: حجز وإتمام جزء

```
مشارك نشط في الختمة
    │
    ├── يفتح صفحة الختمة
    │       ↓
    ├── يرى شبكة الأجزاء (30 خلية ملونة)
    │       ↓
    ├── ينقر على جزء أخضر (متاح)
    │       ↓
    ├── [Modal] "هل تريد حجز الجزء الخامس؟"
    │       ↓ تأكيد
    ├── [Optimistic UI] الجزء يتحول أصفر فوراً
    │       ↓
    ├── [API] POST /reserve → Redis Lock → DB Transaction
    │       ↓ نجاح
    ├── [WebSocket] broadcast → جميع المشاركين يرون التغيير
    │       ↓
    ├── [Toast] "تم حجز الجزء الخامس ✓"
    │
    │   ... المستخدم يقرأ الجزء ...
    │
    ├── يضغط "أتممت الجزء الخامس"
    │       ↓
    ├── [API] POST /complete
    │       ↓
    ├── الجزء يتحول رمادي (مكتمل)
    │       ↓
    └── [WebSocket] broadcast → تحديث شريط التقدم لجميع
```

---

## Flow 4: إدارة طلبات الانضمام

```
منشئ ختمة (requireApproval=true)
    │
    ├── يتلقى إشعار "طلب انضمام من فلان"
    │       ↓
    ├── يذهب لصفحة الختمة → تبويب "الطلبات المعلقة"
    │       ↓
    ├── يرى قائمة المنتظرين
    │       ↓
    ├── يضغط ✅ قبول أو ❌ رفض
    │       ↓ قبول
    ├── [API] PATCH /approve → participant.status = ACTIVE
    │       ↓
    └── [إشعار] المستخدم يتلقى "تم قبول طلبك"
```

---

## Flow 5: مغادرة الختمة

```
مشارك
    │
    ├── يفتح إعدادات الختمة
    │       ↓
    ├── "مغادرة الختمة"
    │       ↓
    ├── [تحذير] "لديك جزء محجوز، ستتركه للآخرين"
    │       ↓ تأكيد
    ├── [API] DELETE /leave
    │       ↓
    ├── يُحرَّر الجزء المحجوز تلقائياً
    │       ↓
    └── يُعاد توجيهه للوحة التحكم
```

---

## Flow 6: اكتمال الختمة

```
الجزء الأخير (30) يُتمَّم
    │
    ├── [Service] khatma.status = COMPLETED
    │       ↓
    ├── [WebSocket] emit('khatma_completed')
    │       ↓
    ├── [FE] Celebration animation 🎉
    │       ↓
    ├── [Notifications] لجميع المشاركين
    │       ↓
    └── [isContinuous=true] → إعادة تشغيل تلقائية (iteration++)
```
